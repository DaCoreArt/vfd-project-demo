# Rubrics

Each deliverable is graded against a four-level rubric: **Accomplished
(100 pts)**, **Proficient (80 pts)**, **Developing (60 pts)**,
**Beginning (0 pts)**.

## Deliverable One

| Criteria | Accomplished | Beginning |
|---|---|---|
| Firehouse identification | Appropriate firehouse chosen with clear rationale; financial and sensory observations well integrated | Inappropriate firehouse or no meaningful concrete experience described |
| Tax return location | All six years/all departments located | No tax returns located |
| Excel spreadsheet | Complete names and available years | No spreadsheet created |
| Financial data extraction | All available years extracted and populated | No data extracted |
| Summary/financial story | Comprehensive, concise, coherent | No summary or story |
| Reflection | Specific, links theory/competencies/experience | Minimal or absent |
| Citations | Correct APA 7th, authoritative sources only | Little/no citation or non-acceptable sources |

## Deliverable Two

| Criteria | Accomplished | Beginning |
|---|---|---|
| Financial metrics analysis | Comprehensive, beyond suggested ratios | Below suggested ratio set |
| Firehouse visitation | Comprehensive sensory description of operations/equipment | No visit or no sensory description |
| Reflection | Specific, links theory/competencies/experience | Minimal or absent |
| Citations | Correct APA 7th, authoritative sources only | Little/no citation or non-acceptable sources |

## Deliverable Three

| Criteria | Accomplished | Beginning |
|---|---|---|
| Community funding scenario | Comprehensive: targets, participation assumptions, donor segmentation, feasibility | Incomplete/unrealistic assumptions |
| Full grant scenario | Comprehensive: eligibility, approval likelihood, timing, restrictions, impact of delay/denial | Little/no analysis |
| Short-term loan scenario | Comprehensive: correct payment calculations, cash flow timing, bridge risk, contingency planning | Missing/incorrect calculations |
| Long-term loan scenario | Accurate calculations across metrics, sound discount rate rationale | Incomplete/incorrect calculations |
| Reflection | Specific, links theory/competencies/experience | Minimal or absent |
| Citations | Correct APA 7th | Little/no citation |

## Deliverable Four

| Criteria | Accomplished | Beginning |
|---|---|---|
| D1 presentation integration | 2+ experiences tied to 2+ theories, decision-oriented | No meaningful integration |
| D2 presentation integration | 2+ quantitative results, clear decision-focused interpretation | Results missing/incorrect, no interpretation |
| D3 presentation integration | Valuation results tied to a clear recommendation | No meaningful use of results |
| Cross-deliverable integration | Multiple theories integrated cohesively across D1–D3 | No integration present |
| Narrative & timing | Clear storyline, within time limit, polished narration | No structure, exceeds time limit, unclear narration |
| Citations | Correct APA 7th | Little/no citation |

## Deliverable Five

| Criteria | Accomplished | Beginning |
|---|---|---|
| Written reflection — learning progression | Explicitly explains D1→D2→D3→D4 progression with specific examples | Vague, minimal, or missing |
| Written reflection — competency development | Clear growth explained across all listed competencies with examples | No meaningful reflection |
| Oral VoiceThread | Synthesizes full project scope into a convincing, employer-focused story | Task summary only, no integration or competency connection |
